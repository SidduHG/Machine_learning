# ML Atlas

An open machine learning school with original notes, worked equations, interactive algorithm labs and practical projects.

See [the roadmap](docs/roadmap.md) for the six-feature plan and [AGENTS.md](AGENTS.md) for the required branch, test, PR and merge workflow.

## Development

Requires Node.js 22.13+ and npm.

```sh
npm ci
npm run dev
npm run build
```

Public learning requires no account. Device-local progress will be clearly labeled. Runtime secrets belong in environment configuration, never Git.
