# Owner-directed ML course revision

The owner reviewed the first notes and requested a more substantial, commercially credible course, restricted to classical machine learning for this release. Deep learning is deferred. This changes the release acceptance criteria before feature 6 is merged.

## Learning product

Keep 30 core lessons in six modules: programming/data, mathematical foundations, supervised learning, model families, unsupervised learning, and ML engineering. Remove neural/attention labs and deep-learning projects from the visible course. Preserve deferred content separately for future development; do not count it as published coverage.

Every active lesson needs an original extended chapter: explicit outcomes and prerequisites, connected explanations, a derivation or quantitative reasoning walkthrough, a realistic decision-making case, and additional exercises with hints and worked solutions. Resource recommendations need named authors/providers, level, exact reading focus, and a task that helps the learner apply the material. Do not treat a list of links or word count as editorial validation.

## Sources and teaching approach

Use ISLP and its official companion labs as a statistical learning reference; Inria's scikit-learn MOOC for sound predictive workflows; Stanford CS229 for mathematical depth; Google ML Crash Course for accessible introductions; and primary algorithm papers for guided research reading. Link third-party materials rather than embedding their books/videos or copying course prose into a commercial product. Write independent examples and original explanations.
