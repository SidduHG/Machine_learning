# Interactive algorithm labs

Learners change parameters, step through training, and see how algorithms transform real numeric data in interactive visualizations.

## Who and why
For curious beginners and developers working toward AI engineering, with an emphasis on understanding through examples and practice.

## Learner workflow
Learners change parameters, step through training, and see how algorithms transform real numeric data in interactive visualizations.

## Included
Implement deterministic mathematical functions and unit tests in lib/algorithms; build regression loss-surface, gradient descent, logistic boundary, k-means, nearest-neighbor, tree split, PCA, neural activation, and attention explorations. Use React Three Fiber for rotatable 3D scatter/surface views with accessible numeric equivalents and WebGL fallback.

## Boundaries
No paid enrollment or identity requirement. No promises of employment or exhaustive coverage of active research. Third-party resources are linked with attribution.

## Acceptance
A learner can complete the described workflow with clear outcomes, understandable feedback, and usable mobile and keyboard interfaces. All implemented behavior is tested where practical and documented honestly.
